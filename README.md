# Holt

House rules for the agent.

This is how I ideate, design, and develop on a locked stack (Next.js, shadcn/ui, Vercel, and the rest when a feature actually needs them). It is a working handbook, not a product. Fork it if it helps. It is incomplete on purpose.

## What it is

A sidebar of jobs — harness, ideate, design, develop — so a new person (or a tired you) reuses the house kit instead of inventing custom CSS and a second UI library.

The straps live in `AGENTS.md`, `design.md`, and `.cursor/rules`. The app is the map.

## Run it

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
